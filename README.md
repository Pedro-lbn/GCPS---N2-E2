# Projeto GCPS - CI/CD e GCS

Repositório estruturado para a implementação de práticas de DevOps, CI/CD e Gestão de Configuração de Software.

## Estrutura do Repositório
* `/docs`: Documentação do projeto, incluindo o Plano de GCS.
* `/api`: Diretório base para a API.
* `/mobile`: Diretório base para a aplicação mobile.

## Regras de Configuração
* **Trunk-Based Development** ativo na branch `main`.
* Ambientes configurados: `staging` e `production`.
* Proteção ativa contra push direto na main.
